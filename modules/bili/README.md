# B站（bili）

让机器人「看」B 站视频并参与互动：

- **看视频**（`bili_watch`）：读标题、简介、字幕和热评；别人发来链接/BV 号时用。
- **自动刷**：定时刷关注的/推荐的视频，按人格决定点赞、评论、回评论、分享给主人（面板配置频率与额度）。
- **看画面**：配置视觉模型后抽帧看视频画面；截图存本机，可随时挑一张发出来（`qq_send_shot` / `qq_list_shots`）。
- **改资料**：按面板权限档位换 B 站头像/签名（`bili_set_avatar` / `bili_set_sign`）。
- **安全**：评论/回复走出站身份闸；被拦或试运行不占次数、不记「已评论」记忆；账号风控码自动当天停写。

实现留在插件包内（`bili/` 目录），本模块经 `api.lib` 引用；数据存在插件数据目录 `bili.json`，截图在工作区。

## 安装说明

插件内置同名模块。从市场安装本模块会**替换内置版本**，需要在面板确认；若加载失败会自动回退内置。

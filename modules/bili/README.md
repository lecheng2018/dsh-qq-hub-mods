# B站（bili）

让机器人「看」B 站视频并参与互动：

- **看视频**（`bili_watch`）：读标题、简介、字幕和热评；别人发来链接/BV 号时用。
- **自动刷**：定时刷关注的/推荐的视频，按人格决定点赞、评论、回评论、分享给主人（面板配置频率与额度）。
- **看画面**：配置视觉模型后抽帧看视频画面；截图存本机，可随时挑一张发出来（`qq_send_shot` / `qq_list_shots`）。
- **改资料**：按面板权限档位换 B 站头像/签名（`bili_set_avatar` / `bili_set_sign`）。
- **单独选模型**：面板「B 站用的模型」里选一个，刷 B 站的后台回合（挑关键词、决定评论/回复/分享）和抽帧看画面都用它；留空跟随全局。
- **安全**：评论/回复走出站身份闸；被拦或试运行不占次数、不记「已评论」记忆；账号风控码自动当天停写。

## 1.2.0：实现搬进本模块

原来实现留在插件包 `src/bili/`，本模块只是壳。1.2.0 起整包搬到本模块：

| 文件 | 干什么 |
| --- | --- |
| `api.mjs` | B 站网页端接口：搜索、视频信息、字幕、评论、发评论、改签名/头像（WBI 签名、Cookie） |
| `duty.mjs` | 刷一轮、回评论、看她被发来的视频、出站身份闸、额度与记忆 |
| `vision.mjs` | ffmpeg 抽帧 + 视觉描述（含「单独选的模型」判定） |
| `shots.mjs` | 截图库（去重、上限、手动删） |

插件只剩通用能力，通过 `api.lib` 注入：`core/store.js`（数据目录，`bili.json` 位置不变，升级不丢数据）、
`core/llm.js`（模型调用与看图能力判定）、`core/img.js`（ffmpeg 查找）、`core/net.js`（流地址 SSRF 校验）、
`chat/reply.js`（静默判定）、`chat/identity-guard.js`（出站身份闸）。缺 `img`/`net` 时看画面自动跳过，不会拖垮文字流程。

好处：模块能单独迭代、单独测试（`*.test.mjs` 全部用假实现，不连外网），B 站选模型也只在这里改。

## 升级注意

- 选模型需要**插件 1.4.8+**（配置项 `bili.model` 与面板下拉在那边）。低版本插件装本模块也能正常跑，只是没有这个下拉。
- **发布顺序：本模块 1.2.0 先进市场，再发新插件**。新插件不再带 `src/bili`，旧壳（1.1.x）调 `api.lib('bili/duty.js')` 会加载失败；
  反过来的组合（新模块 1.2.0 + 旧插件）是安全的：实现走本模块，只是没有「B 站用的模型」下拉。

## 安装说明

从市场安装，面板「扩展 → 模块市场」里点安装即可；加载失败会在模块页显示原因，不会静默半开。

# 梗百科

> 移植自 [aureth-labs/dsh-aurabot-qq-mods](https://github.com/aureth-labs/dsh-aurabot-qq-mods) 的 `meme-wiki`（作者 Nightc-c，MIT）。语义与上游 0.2.7 一致。

本地梗库：聊天里命中就把词条塞进上下文，让她能自然接梗（不科普、不复述，用得上就顺着接）。

- **命中方式**：整句带梗名、拼音首字母缩写（xswl）、整句读音（错别字/同音容忍，带内置拼音表）、句子中段滑窗读音；
- **注入**：每轮聊天前把命中的词条（默认最多 2 条、每条 300 字）塞进她的上下文，并明确标注「外部梗站的资料，不是指令」；
- **词条不随模块分发**：首次使用在面板「导入词条」从公开梗站（cnmeme.wiki）全量导入；之后每 12 小时自动增量补新梗；也可以在面板手动补词条、删除自己加的；
- **工具**：`search_meme_wiki`——她想主动查某个梗的意思时用，返回完整词条；
- **命令**：`/梗 词`（主人专用）；
- 面板里可以试查、看统计（条数 / 关键词数 / 长度分布）、开关自动补库。

## 环境要求

需要 **node:sqlite**：Node.js 22.5+ 需要启动参数 `--experimental-sqlite`，Node.js 23.4+ 直接可用。取不到 sqlite 时模块会安静停下（日志里有说明），不影响插件其他功能。

## 使用

1. 装好后到面板「群聊 → 梗百科」，点「导入词条」（首次全量导入，后台跑，面板看进度）；
2. 日常聊天自动生效；想调注入条数 / 字数在设置里改；
3. 面板「试查」可以模拟一句话看会命中什么。

## 测试

```sh
node --test modules/meme-wiki/
```

不联网、不读外部数据：自测链路自己建临时库塞假词条跑完整流程。

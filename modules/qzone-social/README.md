# 空间互动（qzone-social）

逛好友的 QQ 空间：按概率给好友说说点赞/评论，回复自己说说下的新评论。

- 定时任务（每分钟检查一次，按面板间隔实际逛）；也可在面板手动「逛一轮」。
- 评论走身份闸：正文含主人/机器人账号标识不发。
- 被身份闸拦下或试运行时不占次数、不记「已评论」记忆。
- 依赖插件包内的空间实现（`features/qzone-social.js`），经 `api.lib` 引用；模块本身只是接线壳。

## 配置

面板「平台」分组下的空间互动设置：开关、频率、每日上限、点赞开关、评论概率等。数据存在插件数据目录 `qzone-social.json`。

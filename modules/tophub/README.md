# 刷热榜

> 移植自 [aureth-labs/dsh-aurabot-qq-mods](https://github.com/aureth-labs/dsh-aurabot-qq-mods) 的 `tophub`（作者 RookieApe-tao，MIT）。语义与上游 0.3.1 一致。

热榜巡游：每天定时带她「逛」全网热榜——从榜单里挑几个感兴趣的，看完说说自己的感受，把可能合你胃口的热点私聊分享给你，并把这轮经历写进记忆。全程只看不发言：不评论、不发帖、不用登录任何账号。

- **巡游场次**：默认每天 09:30、21:00 各逛一场（可改时刻）；每场逛 2~3 个榜（接口有频率限制），每个榜看前 15 条；
- **数据来源**：tophub.today 节点页直连为主（被 WAF 拦是常态，自动跳过），失败自动换 60s 聚合接口（vikiboss/60s）兜底；结果缓存半小时 + 全局限速 + 单节点失败冷却，不会高频骚扰对方站点；
- **分享**：只发主人私聊，每场限量（默认 2 条，0 = 只看不分享）；发送失败不记账，下一场还会再试；同一条感想有稳定指纹去重，不会重复打扰；
- **记忆**：每轮逛完都写一条「热榜巡游」经历进记忆库，模型给的可记之事也会记；
- **工具**：`tophub_hot`（看某个榜现在有什么）、`tophub_search`（搜某个话题今天上了哪些榜）——聊天里随口问「现在微博热搜有什么」她就会现查现答；
- **控件**：其他模块可以 `api.use('tophub')` 拿 `hot()/search()/nodes()` 直接用今日热点数据；
- 面板里可以手动逛一轮、翻巡游记录。

## 使用

1. 面板「扩展 → 刷热榜」里配置要逛的榜（内置微博热搜 / 知乎热榜 / 抖音热点 / 今日头条 / B站热门 / 60秒读懂世界，也可以填 tophub.today 节点 id）和巡游时刻；
2. 分享发到主人私聊，先在 QQ Hub 配置里填好主人 QQ；
3. 想让她立刻逛一场，面板点「现在逛一轮」。

## 测试

```sh
node --test modules/tophub/
```

外部 HTTP 全部注入 mock，不打真实网络。

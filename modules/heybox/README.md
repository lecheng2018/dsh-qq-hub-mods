# 刷小黑盒（heybox）

小黑盒（xiaoheihe.cn）游戏社区客户端：

- **逛社区**（`heybox_feed` / `heybox_watch` / `heybox_hot` / `heybox_search` / `heybox_topics`）：信息流、帖子正文与热评、热搜、搜索、分区。
- **写操作**（`heybox_like` / `heybox_comment` / `heybox_post` / `heybox_delete`）：各有权限档位，默认仅主人；发帖前有固定自检流程（先看热搜找角度 → 再搜社区高赞角度 → 素材要有具体信息）。
- **定时逛**：每分钟检查，按面板间隔在后台会话里逛一圈（只读）。
- **安全**：评论/发帖走出站身份闸；发帖配图限制在工作区/数据目录并做图片魔数校验；被拦或试运行不占次数。

需要小黑盒账号 Cookie（面板「平台 → 小黑盒」）。数据存在插件数据目录 `heybox-state.json`。

## 安装说明

插件内置同名模块。从市场安装会**替换内置版本**（面板需确认），加载失败自动回退内置。

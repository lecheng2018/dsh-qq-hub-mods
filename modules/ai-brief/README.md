# AI 新闻推送

> 移植自 [aureth-labs/dsh-aurabot-qq-mods](https://github.com/aureth-labs/dsh-aurabot-qq-mods) 的 `ai-brief`（作者 chienchen-png，MIT）。qq-hub 版去掉了上游依赖 Windows 本机浏览器的「午报·论坛速报」节点，早报 / 晚报全部保留。

每天定时在群里发 AI 简报，来源：

- **知乎热榜**：官方公开接口，固定抓取；
- **Bing 新闻**（可选）：按你配的查询词抓 RSS；
- **自定义媒体 RSS**（可选）：每行「url|来源名」；
- **全网热榜**（可选，默认微博热搜 / 知乎热榜 / 抖音热点；装了「刷热榜」模块会自动接它的数据，没装则跳过）。

抓到的候选项交给模型按你配置的优先级挑几条（新模型发布 > 新 AI 产品 > 公司与人 > 网络热点），每条带一个中文标签和一句她自己的吐槽，链接逐条转短链（is.gd / tinyurl，可在面板关闭）。

- 早报默认 **09:31**、晚报默认 **21:30**，各自可开关、改时间、改条数（1~8）；
- 早晚内容去重：同一天早报发过的链接，晚报不会再发；
- 当天的简报会被缓存：群友直接发「**早报** / **晚报**」（也支持「来一份晚报」这类口令）就能拿到同一份，不重复抓取；
- 主人命令：`/早报`、`/晚报`；
- 面板里可预览、立即发一份到主人私聊，以及改关键词、RSS 源、AI 提示词。

## 使用

1. 装好后到面板「扩展 → AI 新闻推送」，把机器人所在的群加进 QQ Hub 的可用群列表（简报只发可用群）；
2. 想加来源就在「共享设置」里填媒体 RSS / Bing 查询词；不改就是知乎热榜 + 全网热榜；
3. 到点了自动发；也可以随时在面板点「预览」看效果。

## 说明

- AI 提炼失败时自动降级为「原始标题清单」，不会因为模型抖动就不发；
- Bing 新闻 RSS 在部分国内网络拿不到（会拿到 HTML 而不是 RSS）——抓不到就自动跳过，不影响知乎热榜和热榜源；短链服务（is.gd / tinyurl）同理，失败时原样发长链接；
- 能力声明：`network`（抓热榜 / RSS / 短链）、`storage`（当日缓存与去重）、`schedule`（定时发送）、`panel`（管理面板）。能力声明不是沙箱。

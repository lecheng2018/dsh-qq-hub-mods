# QQ Hub 群友蒸馏模块 v2

按群独立、高信噪比提炼群友短口癖与接话节奏的 QQ Hub 扩展模块。

## v2 核心改动

1. **彻底移除全局共享语感底座**：每个群独立维护自己的精简规则库（默认上限 60 条），避免不同群的梗混成大杂烩、规则膨胀导致每轮误命中。
2. **统一消息过滤（`filter.mjs`）**：实时监听与历史抽样共用同一套过滤器，自动排除自身 Bot（含 `chatlog` 中 `who="bot"` 记录）、Q 群管家、配置中的 `fishGuard` 机器人、广告链接、长篇粘贴与报错日志，只看真实群友 2~60 字自然短句。
3. **高信噪比提炼与防人机校验（`prompt.mjs` + `verifier.mjs`）**：
   - 单批最多提炼 3 条，无通用短口癖直接返回 `[]`；
   - 自动拦截具体产品/平台/技术术语、数字价格、省略号填空与「先…再…」「无标点短句」类写作教程描述，剥离套话外壳只留 2~14 字纯粹口癖；
   - 保留截断 JSON 数组的对象抢救能力。
4. **精准聚类与匹配（`store.mjs`）**：
   - 先剥离程度/虚词再用 Jaccard 双重门槛合并，不再仅凭「吐槽 + 短句」乱合并，合并时保留更短的口癖；
   - 匹配只看最近 4 条干净群友短句，短情境要求实词全命中、长情境要求 ≥2 实词且覆盖率 ≥45%；
   - 单条口癖 10 分钟内不重复注入。
5. **克制节流与轻量提示（`index.mjs`）**：
   - 支持单群提炼间隔（默认 180 秒，阈值 35 条）、同群注入冷却（默认 180 秒）、命中后概率注入（默认 35%）、单次最多 1 条；
   - 注入文案改为非强制的轻量顺嘴参考，绝不喧宾夺主；
   - 保留「蒸馏专用模型」（`modelOverride`）配置与自动回退主模型能力。

## 目录结构

- `index.mjs`：扩展入口、生命周期与面板路由
- `filter.mjs`：实时与历史共用的机器人 / 广告 / 长文过滤器
- `prompt.mjs`：高信噪比短口癖提炼提示词
- `verifier.mjs`：截断 JSON 抢救 + 严格质量门禁与规范化
- `store.mjs`：按群隔离存储、Jaccard 聚类、覆盖率匹配与复读冷却
- `history-miner.mjs`：本地 `chatlog` 历史群聊抽样
- `panel.js`：QQ Hub 原生管理面板（支持移动端窄屏）

## 升级说明（从 1.0.0-beta.x 升级）

- 不再读取或展示旧版「全局共享语感底座」（`globalSharing` / `global` 作用域），已有各群专属规则不受影响。
- 可在面板点击「🧹 清理噪点」清理旧版遗留的低频与脏规则，或调用 `purgeDirtyRules()` 专项清洗。

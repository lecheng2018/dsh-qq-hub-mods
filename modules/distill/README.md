# QQ Hub 群友蒸馏模块（MaiBot 风格）

基于 **MaiBot（麦麦）** 的语言风格蒸馏哲学，针对 `dsh-qq-hub` 全新设计的轻量群友语感学习扩展。

## 特性亮点

1. **情境-表达规则抽象**：提炼为 `当“情境 AAAAA”时，可以使用“表达方式 BBBBB”`，不写死模板，不重写人设。
2. **严格防自投毒（Self-Poisoning Guard）**：逐条审查 `source_id` 真实溯源，绝对不学 Bot 自己发过的话，彻底防止复读死循环。
3. **真实经历剥离**：自动识别并过滤群友个人的具体资产、封号、考研等现实生活事实，只学口吻口癖，绝不冒充群友生平。
4. **大容量智能淘汰与锁定**：
   - 规则库支持高达 30 ~ 500 条容量配置（默认 100 条）；
   - 频次累加（高频口癖自动强化加权）；
   - 一键 🔒 锁定经典梗，防止被新数据冲刷淘汰；
   - 超出上限时按活跃度自动淘汰最冷门的一次性偶然词。
5. **QQ Hub 原生交互面板**：提供群规则查看、词频统计、立即提炼测试、手动补录与锁定管理。

## 目录结构

- `index.mjs`：扩展主入口与 API 路由
- `prompt.mjs`：微粒度情境蒸馏 Prompt
- `verifier.mjs`：防投毒与隐私经历过滤管道
- `store.mjs`：数据持久化、LRU + 词频加权与情境匹配
- `panel.js`：QQ Hub 原生视觉风格的管理面板

## 安装与使用

### 1. 本地安装（开发测试）
从本目录执行：
```bash
node scripts/install.mjs
```
模块会自动复制安装至当前 QQ Hub 的用户模块目录，QQ Hub 会秒级热加载生效。

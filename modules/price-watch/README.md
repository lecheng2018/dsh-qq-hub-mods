# 价格监控

> 移植自 [aureth-labs/dsh-aurabot-qq-mods](https://github.com/aureth-labs/dsh-aurabot-qq-mods) 的 `price-watch`（作者 cdcp998，MIT，[原仓库](https://github.com/cdcp998/price-watch)）。按 QQ Hub 模块市场规范落地：设置走宿主自动表单，记忆保留时长由本模块自己管理。

盯住商品价格，只做四件事：

1. **超级好价** —— 值票、评论、收藏都够的成熟好价；
2. **早期好价** —— 信号刚起来、还没被投满的；
3. **降价提醒** —— 比插件上次看到的价格明显便宜（幅度和金额任一命中）；
4. **历史价格最低** —— 比插件记录过的最低价还低。

数据来自什么值得买的公开列表接口（不需要登录），它聚合了京东 / 天猫 / 拼多多 / 抖音商城等平台的爆料，一条查询就能横向比价。

## QQ 里怎么用

| 命令 | 说明 |
|---|---|
| `/监控价格 商品名或链接` | 开始监控（自动识别商品；匹配到多个会给你编号选；`/监控价格 2` 按编号确认） |
| `/查询价格 商品名或链接` | 多平台比价，只列最便宜的前几条（默认 3，可在设置调大） |
| `/价格列表` | 看正在监控的商品和编号 |
| `/取消监控 编号` | 取消一个监控 |
| `/价格记忆` | 看记忆里存了哪些查过的价格 |
| `/忘掉价格 [编号或关键词]` | 删价格记忆；不给参数就全清 |
| `/价格监控帮助` | 用法帮助 |

她也有工具：有人问「XX 多少钱」时她会用 `price_query` 现查；主人可以让她长期盯某件商品（`price_watch_add`）。查到的价格会写一条带「价格监控」标签的记忆（默认保留 30 分钟，可设 0 = 永久），到期自动清掉；被问到「上次那台多少钱」时她想得起来。

## 面板

- 设置表单：检查间隔、降价阈值、好价提醒、提醒冷却、监控时段（北京时间、支持跨午夜）、群聊白名单、记忆保留时长等；
- 监控列表：逐个检查 / 取消 / 全部检查；
- 查价 / 加监控：面板里直接搜，按平台分组看报价；
- 价格记忆：查看和删除。

## 安全与边界

- **群聊白名单默认开启**：没把群号加进白名单之前，群里用不了——宁可先配置，不要一装上就在所有群刷价格。查价 / 加监控对群友是否开放由「允许群友查价 / 加监控」两个开关控制（默认只放查价）；
- 提醒只在真正发出去后计入冷却和计数；发送失败自动回滚状态，下一轮补发；
- 查询失败按指数退避（最长 6 小时），不会每分钟重打接口；
- 记忆只写本插件自己的条目（按「价格监控」标签认领），删的时候也只删自己的；
- 「插件记录最低价」是开始监控之后见到的价格，不是全网史低——文案里不会夸大。

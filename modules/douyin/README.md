# 刷抖音（douyin）

用专用浏览器登录抖音后，让她像普通用户一样刷：

- **看视频**（`douyin_watch`）：读标题、分类、内容摘要和热评；别人发来链接/短链时用。
- **自动刷**（`douyin_browse` / 定时）：真的播放、停留，按人格决定点赞、评论、分享给主人（抖音私信 / QQ）。
- **最近记录**（`douyin_recent`）：查刚刷过的视频及真实链接。
- **私信**：主人私信她在抖音里回；`douyin_send_dm` 只在主人明确指定对象时可用。
- **安全**：评论/分享私信走出站身份闸；验证码/风控自动当天停写；浏览、点赞、评论、分享各有权限档位（默认仅主人）。

需要插件面板「浏览器」页已开启共享浏览器并装好浏览器（`api.browser()`，插件 1.4.7 起），扫码登录在「平台 → 抖音」。数据存在插件数据目录 `douyin.json`；浏览器资料由共享浏览器统一管理。

## 实现位置（2.3.0 起）

实现整包在本模块，不再依赖插件包内的 `src/douyin`：

| 文件 | 职责 |
| --- | --- |
| `lib/duty.mjs` | 刷流主流程、每日上限/写操作闸、分享与私信 |
| `lib/site.mjs` | 抖音网页接口与 DOM 解析（纯解析，无宿主依赖） |
| `lib/browser.mjs` | 共享浏览器租约适配（只走 `api.browser()`；没开时明确报「共享浏览器没开」，不再私自起进程） |
| `lib/media.mjs` | 视频下载、文件名清洗、失败清理（纯 Node） |

宿主能力全部由 `index.mjs` 注入：`core/store`（数据目录）、`chat/reply`（静默判定）、`chat/access`（权限档）、`chat/identity-guard`（出站身份闸）、`api.workspaceDir`（待发视频目录）、`api.browser()`（共享浏览器）。缺任何一项时模块加载即报清楚，不静默半死。

2.3.0 起不带自己的浏览器实现：`minPluginVersion` 提到 `1.4.7-test.20261121.1`（第一个有 `api.browser()` 的插件版本），老宿主不再安装本版本。

## 安装说明

插件内置同名模块。从市场安装会**替换内置版本**（面板需确认），加载失败自动回退内置。
2.3.0 与插件内置版行为一致，只是把实现搬到模块里；数据文件位置不变，升级不迁移、不丢历史。

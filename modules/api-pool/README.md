# 关键词调 API 池

> 移植自 [aureth-labs/dsh-aurabot-qq-mods](https://github.com/aureth-labs/dsh-aurabot-qq-mods) 的 `api-pool`（作者 Epiphuany，MIT）。语义与上游 1.6.0 一致，按 QQ Hub 模块市场规范落地。

只在「指定群」里，群友发某个关键词就自动调用设定好的接口，把返回的文本 / 图片 / 视频 / 音频直接发回群里。

- **纯机械触发**：命中关键词即接管这条消息（她不再回复），完全不经过模型、不费 token。
- **生效范围是全局设置**：生效群白名单 + 触发范围（所有人 / 仅主人）+ 触发人黑名单，对所有 API 统一生效。
- **每条 API 独立**：URL（或「API 库」基地址 + 路径）、GET/POST、请求参数、数据类型（文本 / 图片 / 视频 / 音频 / 混合）、解析表达式、回复模板、错误模板、触发关键词（完全匹配 / 正则匹配，正则支持 `{变量}` 捕获模板）、启停开关、「有效」标记。
- **API 库**：可给一个站点配基地址和可选密钥（自动加 `Authorization: Bearer`）；密钥只存本机，导出配置不会带出去。
- **混合类型**：一条响应里既有文字又有媒体直链时，按配置的消息段顺序分成多条消息依次发回。
- 接口返回的 HTML 标签和实体会自动清洗成纯文本再发进群；媒体直链不受影响。
- 面板里可以单条测试、全部测试（自动刷新「有效」标记）、导入导出配置（导出不带密钥）。

## 使用

1. 装好后到面板「扩展 → 关键词调 API 池」。
2. 「生效群」里填群号（每行一个），选触发范围。
3. 新增一条 API：填名称、URL（或选 API 库填路径）、关键词、数据类型和解析表达式，点「测试」确认能拿到结果，保存即可。
4. 群里发关键词触发；关键词支持 `{变量}` 捕获模板（如 `王者语音{hero}`），捕获到的变量可以用在参数、URL、回复模板里（`{qq}` `{nickname}` `{gid}` `{match}` `{text}` 也是内置变量）。

## 数据与安全

- 池配置存 `api.dataDir()` 下的 `apipool/pool.json`，热重载不丢。
- 库密钥在面板里「只写」：保存后不回显明文；导出文件只含库名和基地址。
- 能力声明：`network`（调用配置的接口）、`storage`（本地保存池配置）、`panel`（管理面板）。能力声明不是沙箱，只帮你判断模块会访问什么。

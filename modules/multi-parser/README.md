# 内容解析（multi-parser）

自动识别聊天里的链接，把内容「拿进来」：

- **支持平台**：B站、微博、小红书、知乎、微信公众号、百度贴吧、番茄小说、GitHub、抖音、小黑盒。
- **解析结果**：标题、作者、高清大图、无水印视频；群里可用合并转发卡片防刷屏，视频可转存群文件。
- **AI 注入**（`feedToAi`）：把最近 3 分钟内解析的图文内容注入模型上下文，让她能接着聊；视频不注入（她看不到画面，只提示「收到一条视频」）。
- **纯解析模式**（`muteAi`）：解析完只说这一条，不再让她接着聊。
- **范围控制**：群/私聊分别开关，可按群禁用（禁用后连链接都不碰）。

配置在面板「平台 → 内容解析」；可复用已配置的 B站/小黑盒 Cookie。媒体文件在工作区 `multi-parser-media/`。

## 安装说明

插件内置同名模块。从市场安装会**替换内置版本**（面板需确认），加载失败自动回退内置。

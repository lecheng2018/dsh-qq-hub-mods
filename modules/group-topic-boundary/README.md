# 群聊话题边界

> 移植自 [aureth-labs/dsh-aurabot-qq-mods](https://github.com/aureth-labs/dsh-aurabot-qq-mods) 的 `group-topic-boundary`（作者 b1ghawk119，MIT）。语义与上游 1.0.0 一致。

可选的群聊话题偏好：只检查机器人即将发出的内容，在明显涉及敏感政治话题时把它转开。不删群友消息、不记录政治倾向、无额外模型调用。

- **三层兜底**：回复文字（`reply`）→ 拆条后的文字/语音（`reply/items`）→ 最终发出的消息段（`send`，覆盖工具和模块直发），语音备注也一起查；
- **规则注入**：给她的系统提示里加一条群聊话题边界规则，说明可以聊什么（日常新闻、生活政策常识、地理、文学、虚构人物），不要深入什么（现实敏感政治人物、争议政治事件、影射、站队、政治动员），被追问/要求猜名字/翻译/念语音/角色扮演时同样遵守；
- **命中处理**：简短回一句「这个话题我就不展开啦，换个聊。」，不复述敏感内容、不邀请继续追问；
- **普通私聊不受限制**；主人在私聊委托代发到群的内容同样受群聊边界约束；
- **词表有意保持短小**：只兜底明确内容（人名/事件），不把「中国、政治、历史、新闻、主席」这类泛词当拦截条件——「天安门看升旗几点」「我的胜率六四开」这类日常话不会被误伤。

## 使用

装好即生效（默认启用）。群聊里试一句「讲讲文革」，她应该简短转开话题；日常新闻和闲聊不受影响。不需要任何配置。

## 测试

```sh
node --test modules/group-topic-boundary/
```
